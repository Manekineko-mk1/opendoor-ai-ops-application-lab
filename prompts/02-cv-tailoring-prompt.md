# CV Tailoring Prompt

Tailor the seed CV for the target role.

Rules:

- Use only facts from the provided seed CV or confirmed candidate facts.
- Do not invent experience, credentials, employers, dates, tools, education, location, work authorization, or impact metrics.
- Preserve truthful scope.
- Emphasize relevant production engineering, automation, operations, SQL, backend, documentation, and stakeholder experience where supported.
- Include ATS-friendly keywords naturally.
- Avoid inflated claims and keyword stuffing.
- Output Markdown first.

Review checklist:

- Every claim is traceable to source material.
- No private data is included unless explicitly approved.
- The result is concise, readable, and role-specific.
