# Cover Letter Prompt

Generate a concise cover letter or application note for the target role.

Emphasize:

- practical AI workflow design
- automation
- production systems
- operations mindset
- documentation and reviewability
- why the role is interesting

Rules:

- Keep the tone direct, human, and professional.
- Do not overstate motivation or experience.
- Do not invent facts.
- Mention the AI-first application workflow only in a way that remains accurate.
- Keep it concise.
